# Vim Practice

`practice.txt` is a scratch file I edited in vim while learning the basics.

```bash
vim practice.txt
```

| Key | Action |
|-----|--------|
| `i` | Enter insert mode |
| `Esc` | Back to normal mode |
| `:w` | Save |
| `:q` | Quit |
| `:wq` | Save and quit |
| `:q!` | Quit without saving |

For more commands, see [`../vim-cheatsheet.jpg`](../vim-cheatsheet.jpg).
